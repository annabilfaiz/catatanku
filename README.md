# CatatanKu 📝

Aplikasi mobile pencatatan harian yang modern, elegan, dan intuitif berbasis **Flutter**. Dirancang untuk memudahkan pengguna dalam mencatat ide, mengelola aktivitas, serta memprioritaskan pekerjaan sehari-hari.

---

## 🚀 Fitur Utama

- **Halaman Pembuka (Splash Screen):** Animasi pembuka yang mulus dan elegan.
- **Autentikasi Pengguna (Login Screen):** Tampilan login dengan input email & password, toggle visibilitas sandi, remember me, dan opsi masuk cepat via Google.
- **Beranda (Dashboard):**
  - Sapaan personal kepada pengguna (`Halo, Faiz 👋`).
  - Pencarian catatan (*real-time search* berdasarkan judul dan isi).
  - Filter catatan berdasarkan kategori (*Semua, Penting, Pribadi, Kerja*).
  - Tampilan kartu catatan (*NoteCard*) dengan kode warna pastel dan indikator prioritas (*Tinggi, Sedang, Rendah*).
- **Detail Catatan:** Membaca catatan lengkap dengan informasi tanggal, kategori, tingkat urgensi, serta opsi hapus catatan.
- **Tambah Catatan:** Menambahkan catatan baru dengan kustomisasi judul, konten, kategori, tingkat prioritas, dan pilihan warna kartu.

---

## 🛠️ Teknologi yang Digunakan

- **Framework:** Flutter (Dart SDK ^3.13.2)
- **Desain & UI:** Material 3, Custom Pastel Color Palette, Google Material Icons & Cupertino Icons
- **Platform Support:** Android, iOS, Web, Windows, macOS, Linux

---

## 💻 Cara Menjalankan Proyek

1. **Clone repositori:**
   ```bash
   git clone https://github.com/faiz/catatanku.git
   cd catatanku
   ```

2. **Pasang dependensi:**
   ```bash
   flutter pub get
   ```

3. **Jalankan aplikasi:**
   ```bash
   flutter run
   ```
